이 프로그램은 읽기 전용이에요. 아무것도 지우거나 고치지 않았고 인터넷도 쓰지 않았어요. 아래 항목이 모두 악성이라는 뜻은 아니에요. 직접 설치한 프로그램인지 확인하고, 각 항목의 '확인하는 법'을 따라 판단하세요.

높음새 항목COM 하이재킹 · COM-001

HKCU가 기존 COM 클래스를 덮어써요 (InprocServer32, 64비트)

위치
HKCU\Software\Classes\CLSID\{9BA05972-F6A8-11CF-A442-00A0C90A8F39}\InprocServer32
대상
C:\Users\me\AppData\Roaming\Microsoft\Crypto\mscorsvc.dll

왜 의심스러운가요?

  • HKLM에 이미 있는 COM 클래스(ShellWindows)를 HKCU에서 덮어써서 다른 파일을 불러오게 해요. COM 하이재킹의 전형적인 형태예요.
  • 디지털 서명이 없는 파일이 사용자 폴더 (사용자 쓰기 가능)에 있어요.
  • 최근 7일 안에 만들어지거나 수정된 파일이에요.
증거 자세히 보기
CLSID
{9BA05972-F6A8-11CF-A442-00A0C90A8F39}
HKLM 원래 값
%SystemRoot%\System32\shdocvw.dll
서명
서명 없음
SHA-256
4b1f0c7e9a2d5c86e13f7a90b6d4e2c158a3f9d07e6b21c4a8f53d9e0b7c6a12

확인하는 법

1) 대상 DLL의 서명자와 위치가 설치한 프로그램과 맞는지 확인하세요. 2) SHA-256 값을 VirusTotal 웹사이트에 직접 붙여 넣어 검색해 보세요.

직접 확인해서 괜찮은 항목이면 다음 검사부터 숨길 수 있어요: Win+R을 누르고 safetysecurity ignore 9f2c1a7be04d6153를 입력하세요.

높음새 항목자동 실행 · RUN-001

자동 실행 등록: WindowsUpdateHelper

위치
HKCU\Software\Microsoft\Windows\CurrentVersion\Run\WindowsUpdateHelper
대상
C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe

왜 의심스러운가요?

  • PowerShell이 인코딩된 명령(-EncodedCommand)을 실행해요. 내용을 숨기는 전형적인 수법이에요.
  • PowerShell 창을 숨겨서(-WindowStyle Hidden) 실행해요.
증거 자세히 보기
명령줄
powershell.exe -nop -w hidden -enc SQBFAFgAIAAoAE4AZQB3AC0ATwBi…

보통새 실행 파일 · FILE-001

새 실행 파일: svchost.exe

위치
C:\Users\me\AppData\Roaming\x7f3\svchost.exe
대상
C:\Users\me\AppData\Roaming\x7f3\svchost.exe

왜 의심스러운가요?

  • 최근 14일 안에 사용자 폴더 (사용자 쓰기 가능)에 생긴 서명 없는 실행 파일이에요.

직접 확인해서 괜찮은 항목이면 다음 검사부터 숨길 수 있어요: Win+R을 누르고 safetysecurity ignore c47a19e05b2d8f31를 입력하세요.

낮음서비스 · SVC-001

의심스러운 서비스: VendorAgent

위치
HKLM\SYSTEM\CurrentControlSet\Services\VendorAgent
대상
C:\Program Files\Some Vendor\agent.exe

왜 의심스러운가요?

  • 서비스 경로에 공백이 있는데 따옴표가 없어요 (C:\Program Files\Some Vendor\agent.exe). 권한 상승에 악용될 수 있는 설정이에요.

직접 확인해서 괜찮은 항목이면 다음 검사부터 숨길 수 있어요: Win+R을 누르고 safetysecurity ignore 0e6b93d4f1a2c758를 입력하세요.

검사 범위

  • COM 하이재킹 (HKCU CLSID)
  • 자동 실행 (Run 키, 시작프로그램, Winlogon, IFEO)
  • 서비스·드라이버
  • 예약 작업
  • 브라우저 정책·바로가기·프록시

  • hosts 파일
  • 사용자 폴더의 새 실행 파일

확인하지 못한 것

  • Defender 로컬 제외 목록: 관리자만 읽을 수 있어요. 설치할 때 '관리자 권한으로'를 고르면 확인해요.
