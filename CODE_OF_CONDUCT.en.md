# Code of Conduct

[한국어](CODE_OF_CONDUCT.md) · **English**

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- We respect everyone, regardless of age, experience, gender, nationality or anything else.
- We kindly help first-time contributors and people asking questions.
- Abusive language, harassment and publishing other people's personal information are not allowed.
- Because this is a security project, distributing real malware or sharing ways to attack other people's PCs is not allowed.

If something goes wrong, let us know through GitHub's private security reporting or contact the repository maintainer (@jiyul-me).
The maintainer keeps reports confidential and handles them fairly.
